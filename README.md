# Task Manager Full-Stack Application

## 📌 Description
A full-stack task management web application that allows users to create, update, and delete tasks.  
The backend is built with Spring Boot and exposes RESTful APIs, while the frontend is implemented using HTML, CSS, and JavaScript.

---

## 🧱 Tech Stack
- **Backend:** Java, Spring Boot, Spring Data JPA
- **Frontend:** HTML, CSS, JavaScript (Vanilla)
- **Database:** H2 (in-memory)
- **Build Tool:** Maven

---

## ⚙️ Features
- Create new tasks
- View all tasks
- Mark tasks as completed / uncompleted
- Delete tasks
- RESTful API design
